# homebrew-allot

Homebrew tap for [Allot](https://github.com/meh7an/allot), which coordinates heavy jobs between the
Claude Code sessions on one machine. Apple Silicon, macOS 14 or newer.

```bash
brew tap meh7an/allot
brew trust --tap meh7an/allot
brew install allot
allot install
```

For the menu bar app:

```bash
brew install --cask allot-app
```

See the [README](https://github.com/meh7an/allot#macos) for what these do, and how to upgrade and
uninstall.
